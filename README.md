## ✨ Key Features

- 🎨 **8 Corporate Color Themes**: Instantly switch between Active Orange, Tech Cobalt, Slate Gray, Emerald Green, Royal Violet, Crimson Executive, Charcoal Minimal, and Deep Teal.
- 📐 **5 Letterhead Layout Variants**: Choose from Active Classic, Modern Executive Band, Minimal Clean Stack, Corporate Page Frame, and Elegant Split.
- 💧 **Watermark Customizer**: Adjust opacity, size, and rotation for text or image watermarks (e.g., "CONFIDENTIAL", "DRAFT", or custom logos).
- ✍️ **Interactive Digital Signature Pad**: Draw your signature directly using a mouse or touch screen, or upload a signature image.
- 📏 **Layout & Spacing Controls**: Fine-tune top content gap, side padding, and line height with zero layout breakage.
- 🖨️ **Pixel-Perfect A4 PDF Export**: Custom `@media print` rules ensure clean, 1-page PDF exports with zero UI clutter.
- 📱 **Full PWA Support**: Installable as a native app on Android, iOS, Windows, and macOS.
- 🔒 **100% Private & Secure**: Runs entirely in the browser—no server uploads or database tracking.
