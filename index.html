How to Use Letterhead Studio

1. Editing & Drafting

Fill out the sidebar fields or directly click on the A4 page preview to type content.

2. Watermark Adjustments

Change watermark opacity, size scale, and rotation angle using the slider controls. Watermarks are strictly constrained inside the page boundaries.

3. Clear All Reset

Use the Clear All button to wipe all default sample text clean for fresh document writing.

4. Save / Export to PDF

Click Print / Export PDF in the top header. In your browser print settings, choose Save as PDF for a sharp single-page document.
